01 // Mission

Making software systems secure and trustworthy

AI CyberSafe Innovations Lab (AICSIL) is an academic research lab dedicated to using the power of artificial intelligence to build robust, proactive defense solutions for real-world cybersecurity problems. We work at the intersection of machine learning, evolutionary algorithms, and applied security — staying ahead of the curve rather than reacting to it.

01 threat_model: config

Configuration Hardening

An AI-powered automated configuration management system that combines efficient hardening with proactive defense against attacks on misconfigured applications.

02 threat_model: llm / finance

LLM Security in Finance

Examining how large language models can be adopted securely and ethically across banking, where automation meets sensitive financial decision-making.

03 threat_model: llm / healthcare

LLM Security in Medical Applications

Studying privacy and security risks introduced when LLMs are integrated into Electronic Health Records and clinical workflows.

04 threat_model: biometrics

Biometric Authentication Security

Building robust facial-recognition verification for online banking while defending against adversarial machine learning attacks on biometric systems.
